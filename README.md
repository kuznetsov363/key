# DentaCare - Сайт стоматологии

Современный одностраничный сайт стоматологической клиники с адаптивным дизайном и интерактивными элементами.

## Особенности

- 🦷 **Современный дизайн** - Минималистичный и профессиональный интерфейс
- 📱 **Адаптивная верстка** - Корректное отображение на всех устройствах
- ⚡ **Высокая производительность** - Быстрая загрузка и плавные анимации
- 🎨 **Интерактивность** - Анимации при скролле, формы с валидацией
- 🚀 **Готов к использованию** - Не требует дополнительной настройки

## Структура сайта

### Секции:
1. **Главная** - Hero-секция с призывом к действию
2. **Услуги** - Полный спектр стоматологических услуг
3. **О нас** - Информация о клинике и преимуществах
4. **Команда** - Представление специалистов
5. **Запись на прием** - Форма обратной связи
6. **Контакты** - Контактная информация и карта

### Функционал:
- Фиксированная навигация с плавной прокруткой
- Мобильное меню (hamburger)
- Анимации при скролле
- Валидация форм
- Маска для телефона
- Счетчики статистики
- Адаптивный дизайн

## Настройка

### Изменение контактной информации:
В файле `index.html` найдите и измените:
- Телефоны в секциях `appointment` и `contact`
- Email адреса
- Адрес клиники
- Режим работы

### Изменение цветовой схемы:
В файле `styles.css` в блоке `:root` измените CSS переменные:
```css
:root {
    --primary-color: #2c5aa0;      /* Основной цвет */
    --secondary-color: #4a90e2;    /* Вторичный цвет */
    --accent-color: #00d4aa;       /* Акцентный цвет */
}
```

### Добавление услуг:
В секции `services` добавьте новые карточки услуг по образцу существующих.

### Изменение команды:
В секции `team` измените информацию о докторах или добавьте новых специалистов.

## Функционал форм

### Форма записи на прием включает:
- Валидацию всех полей
- Маску для телефона
- Отправку данных (демо-режим)
- Уведомления об успешной отправке/ошибках

### Валидация:
- Имя: минимум 2 символа
- Телефон: российский формат
- Email: корректный формат (опционально)
- Услуга: обязательно к выбору
